# Software de terceros incluido en la versión completa

Los binarios completos (los que no acaban en `-ligero`) llevan dentro, sin
modificar, estos programas con sus propias licencias:

| Programa | Licencia | Origen |
| --- | --- | --- |
| Node.js | MIT y otras (ver `runtime/node/LICENSE` tras instalar) | https://nodejs.org |
| Node.js de Termux y sus bibliotecas (solo Android) | varias, ver `runtime/termux/PACKAGES.txt` | https://packages.termux.dev |
| Termux terminal-view y terminal-emulator (solo el APK) | Apache 2.0 | https://github.com/termux/termux-app |
| OmniRoute y sus dependencias npm | MIT (OmniRoute) | https://github.com/cheaper-inference/OmniRoute |
| FreeLLMAPI y sus dependencias npm | MIT (FreeLLMAPI) | https://github.com/tashfeenahmed/freellmapi |

Claude Code no va incluido: es software de Anthropic con su propia licencia.
